พิมพ์สติกเกอร์ QR Code (2 คอลัมน์)

ปรับแต่งระยะรวมทั้งหมด (Global Adjuster)
ความกว้างป้าย (mm): 90.0
ความสูงป้าย (mm): 24.5

ขอบกระดาษ (mm): 5.0
ตัวอย่างก่อนพิมพ์ (Live Preview)
ทั้งหมด 20 รายการ

การตั้งค่า Silent Print (พิมพ์ทันที ไร้หน้าต่างเด้ง)

เนื่องจากระบบเว็บทำงานอยู่บนคลาวด์ (Render) ทำให้เซิร์ฟเวอร์หลังบ้านไม่สามารถส่งสัญญาณตรงไปยังพอร์ต USB ของคอมพิวเตอร์ผู้ใช้ได้โดยตรง คุณสามารถเลือกใช้งานได้ตามความเหมาะสม:

วิธีที่ 1: ใช้ปุ่ม "พิมพ์ด่วน (Direct Print)" ร่วมกับโหมด Kiosk (แนะนำสูงสุด)

สร้าง Shortcut ของ Google Chrome หรือ Microsoft Edge ไว้บน Desktop เพื่อเปิดโหมดพิมพ์เงียบ:

chrome.exe --kiosk-printing "https://your-domain.com/print-qr.html"

เมื่อกดปุ่ม "พิมพ์ด่วน" เบราว์เซอร์จะสั่งส่งงานไปยังเครื่องพิมพ์เริ่มต้น (Default Printer) ทันที 100% โดยไม่เด้งหน้าต่างถาม

วิธีที่ 2: ใช้ปุ่ม "ดาวน์โหลด PDF (Vector PDF)"

ระบบจะสร้างไฟล์ PDF ขนาดตามมิลลิเมตรจริงของสติ๊กเกอร์ (เช่น 90x24.5mm) ลงเครื่องทันทีใน 1 คลิก จากนั้นเปิดไฟล์แล้วสั่งพิมพ์จากโปรแกรม PDF ได้อย่างคมชัดเป๊ะทุกมิลลิเมตร

วิธีที่ 3: ใช้ "พิมพ์ผ่าน USB Thermal (TSPL)"

สำหรับเครื่องพิมพ์สติ๊กเกอร์ความร้อน (Xprinter, Zebra, TSC, Gprinter) ที่ต่อสาย USB/Serial เข้าคอมพิวเตอร์ ระบบจะใช้ Web Serial API สื่อสารโดยตรงกับเครื่องพิมพ์ สั่งพิมพ์ออกมาทันทีโดยไม่ต้องผ่านไดรเวอร์ของวินโดวส์
